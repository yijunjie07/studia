# 使用指南

## AI 答题

每次启动默认进入 MOOC / AI 优课的课程列表，按 **t** 可切换到资源库。选择一门课程，再选 **2. AI 答题**。AI 答题支持常规 MOOC / AI 优课平台，资源库仅提供自动学习。首次需要浏览器登录，之后自动恢复有效的本机登录。任务列表同时显示作业、考试和测验，以及平台完成状态。选定任务后查看执行摘要。

新用户默认使用项目提供的**默认供应商**，无需配置 Key，费用使用项目共享额度。默认供应商固定显示在模型列表顶部，不可修改或删除，界面不显示其接口地址。已有配置的用户保留当前模型，可按回车切换。共享服务可用性取决于供应商和剩余额度；也可选择 **＋ 添加模型** 使用自己的服务。

模型列表用 **↑↓ 选择、回车启用、e 编辑自定义模型、Esc 返回**；实心圆 **●** 表示当前模型，列表显示供应商名称、模型和状态，可填写供应商名称来区分同名模型；旧配置未命名时显示“自定义供应商”。表单只填写供应商名称、接口地址、模型名称和 API Key，用 **Tab / Shift+Tab** 切换字段，再选择 **保存并测试**；Esc 返回上一级并取消编辑，不改动原配置。第一份配置自动启用，新增其他配置不会覆盖或替换当前模型，选中后按回车即可切换。

支持 **OpenAI 兼容的 Chat Completions API 和 Responses API**，保存测试时自动识别并记住可用接口，无需手动选择格式。供应商名称只是显示标签；原生 Gemini、Anthropic 协议仍不支持。旧配置已指定的接口格式继续生效，默认供应商使用预设接口。

- 自定义兼容接口：地址填写 `https://服务商地址/v1`，模型填写服务商提供的 Model ID。程序先测试 Chat Completions，只有服务明确表示接口不支持时才尝试 Responses；HTTP 401、余额不足、超时、普通参数错误和模型不存在不会触发切换。也可填写完整 `/chat/completions` 或 `/responses` 地址，直接指定对应接口。
- DeepSeek：地址填写 `https://api.deepseek.com`，模型填写 `deepseek-chat` 或 `deepseek-reasoner`，Key 使用该服务商的密钥。

编辑自定义模型时原供应商名称、地址和模型已填好，Key 留空保留；换接口地址必须填写新 Key。修改地址、模型或 Key 会在保存测试时重新识别接口；仅改供应商名称保留已识别结果。删除入口位于编辑页，需要确认。删除当前模型后须重新选择一个模型才能答题，程序不会自动换用其他服务。

Key 隐藏输入，和供应商名称、URL、模型及识别结果一起保存到本机用户目录，不回显到终端。内置服务使用项目共享额度，自定义服务由对应账号计费。发送给 AI 的内容只有题干、上下文和选项；不会携带平台 cookies、登录 token、姓名或学号。

任务列表用 **↑↓ 移动、空格勾选／取消、Enter 确认**。顶部 **All** 一次勾选全部可处理任务，再按空格可取消全选；长列表会自动滚动。没有勾选时，回车不会执行。`Esc` 返回，`q` 退出。课程列表按编号进入一门课程。

平台的**附件作业**显示“附件作业／暂不支持”，复选框为 `[-]`，不能勾选；全选和保留选择都会排除，编号输入也不能选中。AI 答题与题目导出均暂不处理此类任务，请到平台完成。识别使用任务目录类型，不会为此打开试卷或启动作答。

任务有开放时间时，列表显示**未开始／已截止**，这些任务同样不可勾选，全选与保留选择会排除。方向键移到任务上，底部显示完整起止时间（北京时间）；编号模式在列表下解释不可选原因。按 `r` 刷新可重新读取开放状态。起止时间格式无法识别时显示“时间未知”，需刷新或到平台核对。程序在读取试卷前及交卷前复核时间；排队期间过期的任务会显示“已跳过”，不阻止后续可用任务。

单份试卷被平台拒绝、题目结构不支持、作答时间耗尽或任务被锁定时，会记录该试卷的失败原因并继续下一份。结束后按试卷汇总成功、失败和跳过数量，每份各计一次。平台登录失效、整体限流或服务不可用、AI 服务故障、交卷结果未知及用户暂停仍会停止派发，剩余任务列为“未执行”，不计为失败。连接预检就失败时尚未处理任何试卷，显示失败原因及未执行数量。

任务列表有固定表头，名称、状态、成绩、剩余次数和类型按列对齐；终端窄于 52 列时隐藏类型列，优先保证名称、状态、成绩和剩余次数可读，暂不可选的提示不受影响。状态来自当前账号的平台作答历史：**已提交**表示有确认的交卷记录，**未提交**表示只有草稿，**未作答**表示没有作答记录。查询失败或平台状态无法识别时显示 **?**。按 `r` 可重新读取状态；此查询不会打开试卷或启动作答计时。本地导出文件或 AI 报告不算平台已提交。

成绩和剩余次数只显示数值，单位放在表头：**0** 是真实零分或次数用完，作业没有剩余机会时显示 **x**（平台返回剩余次数 `-1` 或有限次数已用完）；**--** 表示暂无成绩，**待批**表示等待批阅，**不限**表示不限次数，**?** 表示数据未知。剩余次数采用平台额度，实际能否重答仍受开放时间等平台条件约束。

执行摘要显示任务、供应商名称、模型、连接状态和执行方式。默认采用“答题并自动交卷”。回车开始；`m` 打开模型配置，添加、编辑或切换后保留选好的任务和答题设置；`t` 测试当前 AI 连接；`s` 修改执行方式；`Esc` 返回选择任务，并保留上次选择。仅生成本地答案可在当次设置中选择；每次从课程菜单重新进入 AI 答题，执行方式恢复为“答题并自动交卷”。

答题时，上方显示试卷总进度，下方显示本卷已处理题数、百分比及当前阶段（AI 生成、单题重试、交卷、确认结果）。材料题按子题计数；重试不增加已处理题数。只有校验通过、可提交的题目才计入已处理题数。题目进度达到 100% 表示题目已处理完，交卷是否成功以“已交卷”结果为准。

保存配置后自动测试，模型列表分别显示每份配置的上次测试结果。选中任一模型后，按 `t` 或 Tab 切到“测试连接”按钮，原地显示测试中、结果和耗时；不会启用该模型，测试期间可按 Esc 返回。修改地址、模型或 Key 后旧结果失效，仅改供应商名称不清除连接记录。连接失败仍保留已保存的配置，自定义模型可按 e 修正后重新保存测试；执行摘要用简短状态，本机设置显示当前模型上次通过时间或失败原因。测试仅向 AI 服务发送一道固定的连接测试题，不读取课程题目；该请求仍可能产生服务商费用。执行前也会自动测试，失败时不会打开试卷。HTTP 401 会停止后续任务并提示鉴权失败，请核对服务地址和该服务商的 Key。

执行方式：

1. **仅生成答案（不交卷，无成绩）**：答案只保存在本地，不向平台保存或提交，平台不会评分。获取试卷本身可能创建作答记录并开始计时。结果页会显示“答案已生成 · 未交卷”。需要交卷时，在执行摘要按 `s` → 执行方式 → 答题并自动交卷。
2. **AI 答题并自动交卷**：所有题目都支持、答案格式有效时才交卷。模型自报的置信度只是可选的报告元数据，即使缺失或数值异常也不会阻止采用有效答案。

可自动处理纯文本单选、多选、判断、填空、问答，以及由这些类型构成的纯文本子题。图片、音频、附件、未知题型及无法解析的题目仍需在平台处理，程序不会猜测题意或提交不完整试卷。存在未完成题目时只保存本地报告，不交卷，并在结果页列出原因；不需要人工输入。

单题遇到 AI 响应格式异常、连接超时、HTTP 408/429 或服务端 5xx 时，等待 1 秒、2 秒后分别重试，最多重试 2 次。只重试当前题，已完成的答案保留；每次重试前检查作答时间。重试后仍失败的题目记录为“未完成”，只保存本地报告、不交卷，且不会重复请求；鉴权或配置错误直接停止整个队列；交卷请求不自动重发。

重新选择任务时全部重新调用 AI 作答，不复用旧报告或旧报告中的答案；本次运行内的单题重试不影响其他已完成题目。失败或未完成的题目不会自动询问任何人，也不会用猜测的答案补齐。

程序使用真实经过的时间上报作答时长，不伪造考试时长。平台拒绝请求、时间耗尽或计时请求失败时停止处理。再次选择已提交的任务会尝试开始新一轮作答，历史交卷记录不会导致跳过；是否还有次数、是否开放由平台决定。新一轮重新生成答案，上一轮已交卷报告保存在 `ai_results/<课程名>/history/`；同一轮未交卷的草稿也重新生成全部答案；平台若返回已交卷的同一记录，则停止处理并提示原因。交卷结果未知时先核对平台，不自动重发同一份交卷请求。

## 自动保存与本机设置

课程列表按 **s → 1 模型配置** 打开模型列表，与答题摘要的 **m** 入口相同。按 **2 并发设置** 分别调整 AI 答题和自动学习；还可分别退出 MOOC 与资源库的本机登录，`Esc` 返回课程列表。退出登录后内存中的客户端也会失效，下次进入平台重新登录。

AI 答题和自动学习分别支持 **1–8 路**执行，默认均为 **8**，沿用已保存的有效设置。并发设置页用 ↑↓ 选项目，←→ 或数字调整；Tab 切换保存、取消、恢复默认，Esc 取消。恢复默认只修改草稿，保存后下次运行生效，取消不改变已保存值。上限 8 是程序允许的并发数，不代表供应商或平台一定允许 8 路；执行摘要只显示执行方式，不显示并发数。

AI 并发发生在同一份试卷内：最多 8 道题同时生成，任一道完成后立即校验、保存并补充下一道，不等整批结束。不同试卷继续依次处理，报告和交卷仍统一进行。自动学习并发发生在当前课程的独立资源之间，课程仍顺序处理，MOOC 与资源库共用同一执行方式。并发不控制导出，也不同时启动“学习”和“答题”两个菜单操作。暂停或 Ctrl+C 后停止派发新任务，已经发出的请求可能仍需等待返回或超时；交卷不会自动重发。

并发答题遇到服务限流或暂时不可用时，在途请求共用冷却时间；429/503 的有效 Retry-After 可延长等待（最多 300 秒），每题仍最多重试 2 次。并发不保证速度更快，遇到限流时程序会遵守服务端的等待要求。学习接口限流或登录失效时停止后续任务，不自动重发学习记录。

首次成功读取账号和课程后保存该平台的访问令牌。下次先向平台验证，再显示课程，不再打开浏览器。服务端明确返回未登录/过期（HTTP 或业务状态码 401）时清除失效缓存，重新登录一次；断网、超时、服务端错误或格式异常会停止本次操作并保留缓存。平台决定令牌有效期，保存不等于永久登录。运行中发生的答题/交卷错误不会通过重新登录自动重放请求。

自动保存的内容包括多份模型配置及各自的测试结果、当前启用的模型、两个平台各自的登录令牌、导出格式与范围，以及答题和学习各自的并发数。旧版本保存的置信度偏好仍保留在配置文件中，但不再影响答题和交卷。平台每次默认 MOOC / AI 优课，执行方式每次默认“答题并自动交卷”，课程和具体任务仍在当次选择。

默认保存位置：macOS / Linux 为 `~/.config/icve-ai-assistant/settings.json`；Windows 为 `%LOCALAPPDATA%\icve-ai-assistant\settings.json`。可通过 `ICVE_CONFIG_DIR` 环境变量指定其他目录。内容是未加密的 JSON，macOS / Linux 新建目录为 `700`、配置文件为 `600`，Windows 使用用户目录继承的访问权限。不要分享或上传该文件。写入采用临时文件加原子替换；保存失败会提示，旧配置不会被覆盖。原文件损坏时停止并提示路径，不会静默覆盖。

旧版已保存的单份 AI 配置会自动作为当前模型显示，首次修改模型列表时原子迁移，无需重新输入 Key。退出本机登录只删除本机缓存，不会让浏览器或其他设备退出。

## 本地结果与恢复

- 题目导出：`tiku/<课程名>/`，可输出 `.md`、`.docx`；`-dev` 模式额外输出 JSON 和原始数据。
- AI 报告：`ai_results/<课程名>/<任务标识>.json` 与同名 `.md`，包含 AI 答案、依据、校验结果和执行状态。
- `preview`：仅生成本地答案。
- `needs_review`：存在未完成的题目，未交卷。
- `ai_error`：AI 服务失败，停止后续题目和任务，未交卷。
- `submitted`：交卷后已查询平台记录并确认状态。
- `submission_unknown` / `submitting`：请求可能已发出，但结果未确认；先在网页核对，程序不会自动重发。
- `error`：本份试卷失败，保留错误原因并继续下一份；若标记 `stop_queue=true`，表示平台服务故障，停止队列。

同一账号的同一课程任务使用独立文件锁，避免两个进程重复处理。正常退出会删除 `.lock`；若进程被强制关闭，确认没有其他实例运行、核对网页状态后才可清理该任务的 `.lock`。不要为重试未知结果而直接删除交卷报告。

报告、日志、虚拟环境和本机密钥配置文件均由 .gitignore 排除。内置共享 Key 由项目维护者授权随客户端分发，可从客户端提取；维护者应在供应商端限制额度及模型权限。个人 Key 和平台登录令牌不要加入源码。开启 `-dev` 后的导出原始数据可能包含个人信息，请不要公开上传。

## 题目导出与答案来源

进入课程后选择 **3. 导出题目**，在任务列表中选择作业、考试或测验，再查看执行摘要。格式、文件组织、是否包含“我的答案”沿用上次设置；回车直接开始，`s` 按需修改。

选择范围和文件组织彼此独立：可以只选几份任务，然后选“每份一个文件”或“按课程合并”。合并仅包含当前课程中所选的任务。支持 Markdown、Word 或两种格式同时导出；不同类别的所选题目也可以合并。

- **答案**：来自平台返回的标准答案或答题记录中的答案字段，未逐题验证正确性。
- **我的答案**：当前账号已有的作答记录；选择包含此项只会导出记录，不会开始答题或交卷。
- 平台未返回答案时，文件会标注“平台未返回”，导出功能不会调用 AI 补答。

文件保存到 `tiku/<课程名>/`。AI 模式生成的答案另存到 `ai_results/`，与平台导出的答案来源不同。

## 终端操作与结果

启动后默认显示 MOOC / AI 优课的课程，输入编号进入一门课程；`s` 设置、`t` 切换平台、`r` 刷新课程。进入课程后执行操作，完成后回车返回本课程，或输入 `2` 切换课程，无需重启。

课程首页保留编号进入、`n` / `p` 翻页、`/关键词` 搜索。任务使用空格勾选，无需输入编号范围或分类命令。返回任务列表后，上次选择仍保持勾选，回车即可确认；`r` 刷新状态也会保留勾选。所有交互页面统一按 `Esc` 返回上一级，无需再按回车；课程首页已无上一级时留在首页。模型表单按 Esc 放弃未保存修改。菜单用 `q` 退出，模型表单中的 q 作为普通文本；运行中的任务仍用 Ctrl+C 停止。

重定向标准输入或由脚本调用时，使用兼容的编号输入模式；仅此模式保留 `1,3`、`1-3`、`all`、搜索和类别筛选。

运行时顶部显示任务名、进度条、已完成/总数与用时，下方显示最多 8 行日志，小窗口自动缩减日志区域，长行截断。页面切换在原位置更新，Esc 返回保留选择；运行时回车不回显、不增加空行，也不会带入下一次确认。Ctrl+C 仍可停止。读取未知数量的目录时显示 `?`；导出总数随目录读取逐步增加。交互式终端自动刷新，重定向到文件时不写入动态刷新内容。

自动学习另有“本课资源”进度条：目录读取时显示 `0/?`，去重统计后显示已处理数／总数和百分比，每个资源处理结束就更新。下方显示资源名称及成功、跳过、失败数；已学完或不支持的资源计为跳过，处理失败也计入已处理，取消前未完成的资源不计入。100% 不表示全部学习成功，课程结果仍以成功、跳过、失败统计为准。

结束或 Ctrl+C 中断后清除动态区域，保留结果页：各任务状态、成功/失败数、执行用时、输出文件位置和需要处理的错误。学习管理按课程计数（至少处理一个资源且无捕获错误才算成功，不表示已满足全部课程要求）；导出按写完文件的试卷计数；AI 按试卷计数，本地报告生成与已确认交卷算成功。未完成和交卷结果未知计入失败并单独标注。读取目录等前置错误也会计入失败；未开始的任务不算完成。每次操作单独统计，选择课程与修改设置的时间不计入任务执行用时。

完整业务日志保存在运行目录下的日期 `.log` 文件中。动态面板消失后，可结合日志和本地报告查看详情。`-dev` 会让面板包含调试消息。

无需账号的界面预览：`python -m tools.ui_demo`。该预览只使用模拟数据，不访问平台或 AI。在真实终端可用 `python -m tools.ui_demo --native` 预览原生键盘控件：菜单、课程单选、确认、多选、模型/并发以及执行摘要/结果页，同样只使用合成数据，不写入配置。
