# 使用指南

[返回项目首页](../README.md)

## AI 答题

启动时选择 **3 → 平台 0**，按提示配置：

- **1. 自定义 OpenAI 兼容接口**：输入 API Base URL、Model ID、API Key。示例 URL 为 `https://服务商地址/v1`；也接受完整 `/chat/completions` 地址。远程地址要求 HTTPS，本机服务支持 HTTP。
- **2. DeepSeek**：输入 API Key，选择 `deepseek-chat`、`deepseek-reasoner` 或自定义模型名称。模型可用性取决于服务商和账号。

Key 隐藏输入，仅保存在当前进程内存，不落盘、不写日志。API 调用由用户自己的服务账号计费。发送给 AI 的内容只有题干、上下文和选项；不会携带平台 cookies、登录 token、姓名或学号。

登录后直接选择目标课程，例如《中外音乐与民族技艺实践》，再选择任务类别和具体任务，支持 `1,3`、`1-3` 或 `all`。此流程无需用“跳过课程”反向选择。

执行方式：

1. **仅生成本地答案报告**：不向平台保存或提交答案。但获取试卷本身可能创建作答记录并开始计时。
2. **AI 答题并自动交卷**：只有所有题目都支持、答案格式有效且满足设置的置信度阈值时才交卷。默认阈值为 0.8；模型自报置信度不代表正确率。

可自动处理纯文本单选、多选、判断、填空、问答，以及由这些类型构成的纯文本子题。含音频、图片、附件、无法识别的公式、未知题型、缺少题干或选项、低置信度或漏答时会标记需要人工处理，整份任务不会自动交卷。音乐听辨、乐谱识别和文件上传作业目前需要人工完成。

程序使用真实经过的时间上报作答时长，不伪造考试时长。平台拒绝请求、时间耗尽或计时请求失败时停止处理。已提交或状态未知的历史作答不会重做。

## 本地结果与恢复

- 题目导出：`tiku/<课程名>/`，可输出 `.md`、`.docx`；`-dev` 模式额外输出 JSON 和原始数据。
- AI 报告：`ai_results/<课程名>/<任务标识>.json` 与同名 `.md`，包含 AI 答案、依据、校验结果和执行状态。
- `preview`：仅生成本地答案。
- `needs_review`：存在未完成的题目，未交卷。
- `submitted`：交卷后已查询平台记录并确认状态。
- `submission_unknown` / `submitting`：请求可能已发出，但结果未确认；先在网页核对，程序不会自动重发。
- `skipped`：存在历史提交或试卷已提交。
- `error`：错误已写入报告，队列停止。

同一账号的同一课程任务使用独立文件锁，避免两个进程重复处理。正常退出会删除 `.lock`；若进程被强制关闭，确认没有其他实例运行、核对网页状态后才可清理该任务的 `.lock`。不要为重试未知结果而直接删除交卷报告。

报告、日志、虚拟环境和密钥配置文件均由 .gitignore 排除。开启 `-dev` 后的导出原始数据可能包含个人信息，请不要公开上传。

## 题目导出与答案来源

选择菜单 **2 → 平台 0**，登录后依次选择课程、Markdown / Word 格式、是否包含“我的答案”，以及作业、考试或测验。

- **答案**：来自平台返回的标准答案或答题记录中的答案字段，未逐题验证正确性。
- **我的答案**：当前账号已有的作答记录；选择包含此项只会导出记录，不会开始答题或交卷。
- 平台未返回答案时，文件会标注“平台未返回”，导出功能不会调用 AI 补答。

文件保存到 `tiku/<课程名>/`。AI 模式生成的答案另存到 `ai_results/`，与平台导出的答案来源不同。
