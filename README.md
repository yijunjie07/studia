# ICVE AI Assistant · 智慧职教 AI 助手

智慧职教常规 MOOC / AI 优课的课程管理、题目导出和 AI 答题工具。

当前维护者：[yijunjie07](https://github.com/yijunjie07) · [使用指南](docs/USAGE.md) · [开发与目录说明](docs/DEVELOPMENT.md) · [接口说明](docs/EXAM_PROTOCOL.md)

## 功能

| 课程内操作 | 功能 |
| --- | --- |
| 1. 自动学习 | 完成课程学习任务，并按主题自动参与课程讨论、提交五星课程评价 |
| 2. AI 答题 | AI 作答并自动交卷，也可选择仅生成报告 |
| 3. 导出题目 | 保存题目和已有答案，支持 Markdown / Word |
| 课程列表的 s 设置 | 管理模型、测试 AI 连接，或退出已保存的平台登录 |

AI 答题及题目导出支持 `ai.icve.com.cn`，资源库当前支持学习管理。课程讨论和课程评价仅对 MOOC / AI 优课的自动学习生效，资源库不涉及。附件作业单独标为“暂不支持”，不能勾选，全选会排除；请在平台完成。含音频、图片、附件的题目仍需人工处理；不能保证答案正确或完成全部课程要求。

任务列表会识别开放时间，标明“未开始／已截止”并排除不可作答任务；方向键移到任务上可查看完整起止时间。排队期间过期的任务自动跳过，其他可用任务继续执行。

批量 AI 答题遇到单份试卷失败会记录原因并继续，最后按试卷汇总成功、失败、跳过及未执行数量。登录失效、服务不可用、交卷结果未知或用户暂停时停止队列。

## 安装与启动

推荐使用 **uv**，macOS、Windows、Linux 都使用下面这套命令。uv 会管理 Python 和项目依赖，无需手动创建或激活虚拟环境。

### 1. 首次安装

先安装 [Git](https://git-scm.com/downloads) 和 [uv](https://docs.astral.sh/uv/getting-started/installation/)，安装后重新打开终端（Windows 使用 PowerShell）。在想存放项目的目录执行：

```bash
git clone https://github.com/yijunjie07/icve-ai-assistant.git
cd icve-ai-assistant
uv sync --locked --python 3.12
uv run StartWork.py
```

首次安装会下载所需的 Python 3.12 和依赖（已有可用版本时复用）。启动后，在浏览器完成平台登录，再回到终端操作。

### 2. 以后启动

在项目目录（包含 `StartWork.py` 的文件夹）打开终端，执行：

```bash
uv run StartWork.py
```

### 3. 更新项目

源码运行显示 `pyproject.toml` 中的版本号，当前为 **4.3.0**。源码启动不会自动下载更新，打包发布版使用发布标签作为版本号。

先退出正在运行的程序，再在项目目录执行：

```bash
git pull --ff-only
uv sync --locked
uv run StartWork.py
```

## 使用

每次启动默认进入 MOOC / AI 优课，自动恢复有效登录，直接显示课程。真实终端里用 `↑↓` 把高亮移到目标课程后按 `Enter` 进入，再选择自动学习、AI 答题或导出题目（重定向或脚本输入时仍可用编号，例如输入 `2` 进入第 2 门课程）。任务列表用方向键移动、空格勾选、回车确认，顶部 `All` 可全选或取消全选。`t` 切换平台，`s` 打开设置。

真实终端中的菜单、课程选择、确认和多选都使用同一套键盘操作：`↑↓` 移动，`Enter` 采用当前高亮项或确认，`Tab` / `Shift+Tab` 在列表与按钮之间移动焦点，`Esc` 返回上一步，`q` 退出，`PageUp` / `PageDown` 翻页。只有页面明确标注的单个按键（结果页的 `1` / `2`、模型列表的 `t` / `e`、任务列表的 `r`）才会触发操作，不会再有隐藏的编号快捷键；在 `/` 打开的搜索框里输入时按键保持字面文本，不会被当作快捷键。课程和任务的单选选择器支持 `/关键词` 搜索，`Enter` 在搜索框应用筛选并回到列表，`Esc` 先退出搜索再返回。导出和 AI 先选任务，再看执行摘要：摘要显示当前设置和所选任务，`Enter` 直接开始，可用 `s` 修改设置、`m` 选择模型、`t` 测试连接。AI 默认答题并自动交卷；全部题目通过校验才交卷，也可切换为仅生成本地答案。模型自报的置信度仅供参考，不会阻止采用有效答案。受支持的题目若 AI 没有给出可用答案，会在终端显示题号、原因、材料和选项等待人工输入（`B` 是选项，不是返回；`:s`、`Esc`、`Ctrl-C` 或 EOF 保存退出，不交卷），补答后整份试卷会再询问一次 `N/N 题已完成，交卷提交整份试卷？`，默认不提交；此时按 `Esc`、`q`、`Ctrl-C` 或 EOF 会保存并停止剩余队列，直接回车或选“否”只放弃本份试卷。图片、音频、附件等不支持的题目不会进入人工补答。同一份试卷、同一轮作答再次执行时，未改动的题目直接复用已校验答案（含人工答案），只重新生成改动或缺失的题目；上次未完成的问题直接再次提示人工输入，不再调用 AI。已交卷任务可再次选择作答，是否开放由平台决定；上一轮报告会保留。执行结果页显示每份任务的完成状态、错误原因和生成的文件，`Enter` 或 `1` 返回本课程，`2` 切换课程，`Esc` 返回本课程，`q` 退出。运行时原地显示进度和最多 8 行日志，小窗口自动缩减日志区域，结束后保留结果、文件位置和失败原因，可回到当前课程继续操作。无需登录可执行 `uv run python -m tools.ui_demo` 预览静态界面，`uv run python -m tools.ui_demo --native` 在真实终端预览原生键盘控件。

AI 已内置项目提供的**默认供应商**，固定显示在模型列表顶部。新用户无需填写 Key，使用项目共享额度；可用性以供应商和剩余额度为准。已有模型的用户升级后保留当前选择，可随时切换到默认供应商。

要用自己的服务，选择 **＋ 添加模型**，填写供应商名称、接口地址、模型名称和 API Key；按 Tab 切换字段，再选择 **保存并测试**。地址可填 `https://服务商地址/v1`，程序会自动识别兼容的 Chat Completions 或 Responses 接口并记住结果，无需选择接口格式。填写完整 `/chat/completions` 或 `/responses` 地址时直接使用对应接口。

自动识别先测试 Chat Completions，只有服务明确表示接口不支持时才尝试 Responses；鉴权失败、余额不足、超时、普通参数错误和模型不存在都不会触发切换。

模型列表用 ↑↓ 选择、回车启用，按 `e` 编辑自定义模型，按 `t` 或选择“测试连接”测试当前选中项，原地显示状态和耗时，不切换启用模型；可保存多份配置，列表和答题摘要显示供应商名称与模型；旧配置未命名时显示“自定义供应商”。答题摘要按 `m` 直接切换模型，已选任务不变；课程列表的 **s 设置 → 模型配置** 也能打开同一列表。默认供应商不可修改或删除，界面不显示其接口地址。供应商名称是自定义标签，仅改名称保留已识别结果；修改地址、模型或 Key 会在保存测试时重新识别。

配置保存在仓库外的用户目录（macOS / Linux 为 `~/.config/icve-ai-assistant/settings.json`），包含访问令牌和 Key。这是未加密的本地 JSON；macOS / Linux 新建目录权限为 `700`，文件权限为 `600`。不要分享该文件。导出选项、并发数也会保存；每次进入 AI 答题默认答题并自动交卷，可在执行摘要中修改。

**AI 答题**和**自动学习**最多同时处理 **8 项**，谁完成就先保存结果、更新进度并立刻补进下一项，不等待整批结束。AI 的慢题不会挡住其他已完成题目的进度；报告和交卷仍按原题序排列；限流重试遵守服务端的等待要求。在 **s 设置 → 2 并发设置** 分别调整答题和学习并发（1–8，默认 8），保存后下次运行生效。实际速度仍受模型服务和平台响应影响。

自动学习同时显示课程进度和本课资源进度，包括已处理数、总数、百分比，以及成功、跳过、失败统计。读取目录时总数显示 `?`；100% 表示资源处理完毕，是否成功以结果统计为准。

资源处理完成后，MOOC / AI 优课的自动学习还会处理课程活动主题讨论和课程评价：讨论回复由 AI 按主题生成、最多 20 字；课程评价固定五星，评语由 AI 按课程生成（复用已配置的 AI 模型）。已参与的讨论、已评价的课程，以及未开始或已截止的讨论都会跳过。开始前会验证 AI 连接，开始学习后自动提交讨论和评价。读取状态失败、AI 生成失败或写入结果未知时都不会当作成功，也不会自动重发。

## 文件在哪里

| 内容 | 本地位置 |
| --- | --- |
| 导出的题目与平台答案 | `tiku/<课程名>/` |
| AI 答案与执行报告 | `ai_results/<课程名>/` |
| 课程结构导出 | `exports/structure/` |

导出功能不调用 AI。“我的答案”来自当前账号的已有作答记录。具体操作、自动交卷条件及异常恢复方式见 [使用指南](docs/USAGE.md)。这些本地结果、日志和密钥文件已由 Git 忽略。
