# 使用指南

[返回项目首页](../README.md)

## AI 答题

每次启动默认进入 MOOC / AI 优课的课程列表，按 **t** 可切换到资源库。选择一门课程，再选 **3. AI 答题**。AI 答题支持常规 MOOC / AI 优课平台，资源库仅提供继续学习。首次需要浏览器登录，之后自动恢复有效的本机登录。任务列表同时显示作业、考试和测验，以及平台完成状态。选定任务后查看执行摘要；首次配置 AI 服务，以后自动使用已保存的配置：

- **1. 自定义 OpenAI 兼容接口**：输入 API Base URL、Model ID、API Key。示例 URL 为 `https://服务商地址/v1`；也接受完整 `/chat/completions` 地址。远程地址要求 HTTPS，本机服务支持 HTTP。
- **2. DeepSeek**：输入 API Key，选择 `deepseek-chat`、`deepseek-reasoner` 或自定义模型名称。模型可用性取决于服务商和账号。

Key 隐藏输入，和 URL、模型一起保存到本机用户目录，不回显到终端。API 调用由用户自己的服务账号计费。发送给 AI 的内容只有题干、上下文和选项；不会携带平台 cookies、登录 token、姓名或学号。

任务列表用 **↑↓ 移动、空格勾选／取消、Enter 确认**。顶部 **All** 一次勾选全部任务，再按空格可取消全选；长列表会自动滚动。没有勾选时，回车不会执行。`Esc` 返回，`q` 退出。需要同时操作多门课程时，从课程列表按 `m` 进入同样的勾选界面。

任务列表有固定表头，名称、状态、成绩、剩余次数和类型按列对齐。状态来自当前账号的平台作答历史：**已提交**表示有确认的交卷记录，**未提交**表示只有草稿，**未作答**表示没有作答记录。查询失败或平台状态无法识别时显示 **?**。按 `r` 可重新读取状态；此查询不会打开试卷或启动作答计时。本地导出文件或 AI 报告不算平台已提交。

成绩和剩余次数只显示数值，单位放在表头：**0** 是真实零分或次数用完，作业没有剩余机会时显示 **x**（平台返回剩余次数 `-1` 或有限次数已用完）；**--** 表示暂无成绩，**待批**表示等待批阅，**不限**表示不限次数，**?** 表示数据未知。剩余次数采用平台额度，实际能否重答仍受开放时间等平台条件约束。

执行摘要显示任务、模型、连接状态、执行方式和最低置信度。默认采用“答题并自动交卷”，置信度默认为 **0.8**；修改过置信度时沿用已保存的值。回车开始；`t` 测试 AI 连接；`s` 打开设置，按需修改执行方式或置信度；`b` 返回选择任务，并保留上次选择。仅生成本地答案可在当次设置中选择；每次从课程菜单重新进入 AI 答题，执行方式恢复为“答题并自动交卷”。

保存配置后显示未测试；执行摘要用简短连接状态，本机设置中保留上次通过时间和失败原因。修改地址、模型或 Key 后需要重新测试。测试仅向 AI 服务发送一道固定的连接测试题，不读取课程题目；该请求仍可能产生服务商费用。执行前也会自动测试，失败时不会打开试卷。HTTP 401 会停止后续任务并提示鉴权失败，请核对服务地址和该服务商的 Key。

执行方式：

1. **仅生成答案（不交卷，无成绩）**：答案只保存在本地，不向平台保存或提交，平台不会评分。获取试卷本身可能创建作答记录并开始计时。结果页会显示“答案已生成 · 未交卷”。需要交卷时，在执行摘要按 `s` → 执行方式 → 答题并自动交卷。
2. **AI 答题并自动交卷**：只有所有题目都支持、答案格式有效且满足设置的置信度阈值时才交卷。默认阈值为 0.8；模型自报置信度不代表正确率。

可自动处理纯文本单选、多选、判断、填空、问答，以及由这些类型构成的纯文本子题。AI 把握不足或答案无效时，直接显示该题、材料和选项，让你手动补答；有效答案会接着用于当次交卷。单选输入 `B`，多选输入 `AC`，判断输入对/错，填空按提示逐空输入。图片、音频、附件、未知题型及无法解析的题目仍需在平台处理，程序不会猜测题意或提交不完整试卷。

单题遇到 AI 响应格式异常、连接超时、HTTP 408/429 或服务端 5xx 时，等待 1 秒、2 秒后分别重试，最多重试 2 次。只重试当前题，已完成的答案保留；每次重试前检查作答时间。重试后仍失败会转入手动补答。鉴权或配置错误直接停止；低置信度、不支持的题型不会反复请求；交卷请求不自动重发。

补答时输入 `:q` 可暂停并保存，结果显示“待补答”，不算失败。重新选择同一任务时会核对当前题目，沿用匹配的已有答案，只补未完成题目；内容或选项改变的题目会重新处理。人工补答期间平台计时仍继续。

程序使用真实经过的时间上报作答时长，不伪造考试时长。平台拒绝请求、时间耗尽或计时请求失败时停止处理。已提交或状态未知的历史作答不会重做。

## 自动保存与本机设置

课程列表按 **s** 打开本机设置，支持修改 AI 服务、清除 AI 配置、分别退出 MOOC 与资源库的本机登录，按 **5** 测试 AI 连接；`b` 返回课程列表。退出登录后内存中的客户端也会失效，下次进入平台重新登录。修改时 URL 和模型可回车保留；只有 URL 不变时，Key 才能留空复用。换服务地址需要重新填写 Key，防止把旧服务的 Key 发给新服务。

首次成功读取账号和课程后保存该平台的访问令牌。下次先向平台验证，再显示课程，不再打开浏览器。服务端明确返回未登录/过期（HTTP 或业务状态码 401）时清除失效缓存，重新登录一次；断网、超时、服务端错误或格式异常会停止本次操作并保留缓存。平台决定令牌有效期，保存不等于永久登录。运行中发生的答题/交卷错误不会通过重新登录自动重放请求。

自动保存的内容包括 URL、模型、API Key、两个平台各自的登录令牌、导出格式与范围、最低置信度。平台每次默认 MOOC / AI 优课，执行方式每次默认“答题并自动交卷”，课程和具体任务仍在当次选择。

默认保存位置：macOS / Linux 为 `~/.config/icve-ai-assistant/settings.json`；Windows 为 `%LOCALAPPDATA%\icve-ai-assistant\settings.json`。可通过 `ICVE_CONFIG_DIR` 环境变量指定其他目录。内容是未加密的 JSON，macOS / Linux 新建目录为 `700`、配置文件为 `600`，Windows 使用用户目录继承的访问权限。不要分享或上传该文件。写入采用临时文件加原子替换；保存失败会提示，旧配置不会被覆盖。原文件损坏时停止并提示路径，不会静默覆盖。

升级前只保存在内存中的登录和 Key 无法自动恢复，因此升级后首次仍需输入一次。退出本机登录只删除本机缓存，不会让浏览器或其他设备退出。

## 本地结果与恢复

- 题目导出：`tiku/<课程名>/`，可输出 `.md`、`.docx`；`-dev` 模式额外输出 JSON 和原始数据。
- AI 报告：`ai_results/<课程名>/<任务标识>.json` 与同名 `.md`，包含 AI 答案、依据、校验结果和执行状态。
- `preview`：仅生成本地答案。
- `paused`：等待手动补答，已有答案保留；重新选择任务可继续。
- `needs_review`：存在未完成的题目，未交卷。
- `ai_error`：AI 服务失败，停止后续题目和任务，未交卷。
- `submitted`：交卷后已查询平台记录并确认状态。
- `submission_unknown` / `submitting`：请求可能已发出，但结果未确认；先在网页核对，程序不会自动重发。
- `skipped`：存在历史提交或试卷已提交。
- `error`：错误已写入报告，队列停止。

同一账号的同一课程任务使用独立文件锁，避免两个进程重复处理。正常退出会删除 `.lock`；若进程被强制关闭，确认没有其他实例运行、核对网页状态后才可清理该任务的 `.lock`。不要为重试未知结果而直接删除交卷报告。

报告、日志、虚拟环境和密钥配置文件均由 .gitignore 排除。开启 `-dev` 后的导出原始数据可能包含个人信息，请不要公开上传。

## 题目导出与答案来源

进入课程后选择 **2. 导出题目**，在任务列表中选择作业、考试或测验，再查看执行摘要。格式、文件组织、是否包含“我的答案”沿用上次设置；回车直接开始，`s` 按需修改。

选择范围和文件组织彼此独立：可以只选几份任务，然后选“每份一个文件”或“按课程合并”。合并仅包含所选内容，批量课程分别生成文件。支持 Markdown、Word 或两种格式同时导出；不同类别的所选题目也可以合并。

- **答案**：来自平台返回的标准答案或答题记录中的答案字段，未逐题验证正确性。
- **我的答案**：当前账号已有的作答记录；选择包含此项只会导出记录，不会开始答题或交卷。
- 平台未返回答案时，文件会标注“平台未返回”，导出功能不会调用 AI 补答。

文件保存到 `tiku/<课程名>/`。AI 模式生成的答案另存到 `ai_results/`，与平台导出的答案来源不同。

## 终端操作与结果

启动后直接显示上次平台的课程，输入编号进入一门课程；`m` 批量选择、`s` 设置、`t` 切换平台、`r` 刷新课程。进入课程后执行操作，完成后回车返回本课程，或输入 `2` 切换课程，无需重启。

课程首页保留编号进入、`n` / `p` 翻页、`/关键词` 搜索。任务和批量课程使用空格勾选，无需输入编号范围或分类命令。返回任务列表后，上次选择仍保持勾选，回车即可确认；`r` 刷新状态也会保留勾选。普通菜单用 `b` 返回、`q` 退出。隐藏输入 Key 时用 Ctrl+C 退出。

重定向标准输入或由脚本调用时，使用兼容的编号输入模式；仅此模式保留 `1,3`、`1-3`、`all`、搜索和类别筛选。

运行时顶部显示任务名、进度条、已完成/总数与用时，下方固定显示最近 8 行日志，长行截断。读取未知数量的目录时显示 `?`；导出总数随目录读取逐步增加。交互式终端自动刷新，重定向到文件时不写入动态刷新内容。

结束或 Ctrl+C 中断后清除动态区域，保留结果页：各任务状态、成功/失败数、执行用时、输出文件位置和需要处理的错误。学习管理按课程计数（至少处理一个资源且无捕获错误才算成功，不表示已满足全部课程要求）；导出按写完文件的试卷计数；AI 按试卷计数，本地报告生成与已确认交卷算成功。待人工处理和交卷结果未知计入失败并单独标注。读取目录等前置错误也会计入失败；未开始的任务不算完成。每次操作单独统计，选择课程与修改设置的时间不计入任务执行用时。

完整业务日志保存在运行目录下的日期 `.log` 文件中。动态面板消失后，可结合日志和本地报告查看详情。`-dev` 会让面板包含调试消息。

无需账号的界面预览：`python -m tools.ui_demo`。该预览只使用模拟数据，不访问平台或 AI。
