# 任务开放时间字段核对

日期：2026-10-10（北京时间）。本次使用已有登录只读查询任务目录，并读取官网公开前端；未调用试卷、学习写入、模型或交卷接口来复现拒绝。

## 一手来源

- [公开任务卡片 SjCard](https://ai.icve.com.cn/js/chunk-c13dfc0a.1791603407155.js)，同[附件类型研究](2026-10-10-attachment-homework.md)所核对脚本。
- 真实 GET `/course/exam/record/getExamListByStudent` 返回的目录字段；只记录与问题相关的时间和状态，不保存账号令牌或学生标识。
- 用户提供的任务失败与平台列表截图：程序返回 code=205；平台标为“未开始”，开放时间为 2026-12-28 00:00:00 至 2026-12-31 23:59:59。

## 核实结果

| 来源 | 条件或字段 | 含义 |
| --- | --- | --- |
| SjCard | `-1==n.status` | 按钮“未开始”，没有答题点击处理 |
| SjCard | `-2==n.status` | 按钮“已结束”，没有答题点击处理 |
| SjCard | `0==n.status`、`3==n.status` | 分别“开始答题”“再次答题” |
| SjCard | `n.startTime`、`n.endTime` | “起止时间”，缺失显示 `--` |
| 真实目录：拓展测试1 | `status=-1`；`startTime=2026-12-28 00:00:00`；`endTime=2026-12-31 23:59:59` | 与截图一致，当前不可开始 |
| 真实目录：学情测验 | `status=3`；2026-08-31 至 2026-12-31 | 可再次作答，不因提交历史被当作未开放 |

目录状态与个人作答历史状态不是同一套枚举。原程序只展示完成状态、只拦截附件，忽略目录中的开放状态，导致未开始的考试可以勾选并进入试卷请求，平台拒绝后按通用失败终止队列。

## 修复边界

目录服务端状态优先；本地用北京时间比较日期，补充防止排队时已到截止时间的任务继续开卷或交卷。客户端不会改写起止时间、绕过平台限制，日期或服务端状态变更后通过刷新重新读取。

未核实 code=205 的所有含义，因此保留其通用错误处理。只对明确目录限制使用可继续队列的“跳过”，不自动重放拒绝或结果未知的写请求。
